## 어떻게 동작하나

- 이름 **어디든** 단어가 들어 있으면 걸림(부분 일치).
- 걸리면: 이름 정할 때 "랭킹 제외" 안내 창, 은퇴해도 랭킹에 안 올라감, 이미 올라간 기록도 랭킹 화면에서 안 보임(서버 기록은 그대로).
- 막지는 않음: 그 이름으로 게임은 계속할 수 있음.
