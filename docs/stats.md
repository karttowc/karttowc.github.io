# 플레이 인원 기록

찬우가 "몇 명 플레이했어?" 물으면 여기부터 본다. 마지막 날 다음부터만 새로 세서 아래에 이어 붙인다.

- 기준: 익명 플레이 기록(`logs.py`)의 uid(기기) 수. 기록 끈 사람은 빠짐. 날짜는 한국 시간.
- 방문(GoatCounter)은 게임 안 한 사람도 포함이라 플레이 인원보다 큼.
- 마지막 날(오늘)은 그날 도중에 센 값이라 나중에 조금 늘 수 있음.
